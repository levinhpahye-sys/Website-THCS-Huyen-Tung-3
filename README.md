# CỔNG HỌC TẬP TRỰC TUYẾN - TRƯỜNG THCS HUYỀN TỤNG

Website học tập trực tuyến, kỹ năng sống và giáo dục an toàn học đường dành cho học sinh Trường THCS Huyền Tụng.

## Cấu trúc thư mục tải lên GitHub:
- `index.html`: File giao diện trang chủ hoàn chỉnh (sử dụng Tailwind CSS CDN, không cần build).
- `images/`: Chứa hình ảnh cổng trường THCS Huyền Tụng (`truong-thcs-huyen-tung.jpg`).

## Cách đưa lên GitHub Pages miễn phí:
1. Tạo một repository mới trên GitHub (Ví dụ: `thcs-huyen-tung`).
2. Tải toàn bộ nội dung trong thư mục này (`index.html` và thư mục `images/`) lên nhánh `main`.
3. Vào **Settings** -> **Pages** trên GitHub:
   - Branch: chọn `main`
   - Folder: chọn `/ (root)`
   - Nhấn **Save**.
4. Sau 1 phút, website sẽ hoạt động online tại địa chỉ: `https://<ten-tai-khoan>.github.io/<ten-repo>/`
